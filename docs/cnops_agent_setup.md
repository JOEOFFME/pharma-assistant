# CNOPS medicine data and web-first agent

Normal chat now uses web research as its primary path. OpenRouter remains the main
model and uses the existing private `OPENROUTER_API_KEY`. Medicine questions prefer
CNOPS evidence; general questions can use a broader public-web tool. The prior
finite medicine-example answer is disabled by default. General information remains
separate from diagnosis, personal prescribing, dosing and substitution.

## Windows update

Stop the old server, update the working branch, and preserve your existing private key:

```powershell
git pull origin codex/assistant-answers-voice
uv sync --frozen --extra speech
notepad .env
```

The relevant settings are:

```dotenv
ASSISTANT_NLU=openrouter
ASSISTANT_AGENT=true
ASSISTANT_WEB_SEARCH=true
ASSISTANT_WEB_FIRST=true
OPENROUTER_MODEL=openai/gpt-4.1
OPENROUTER_FALLBACK_MODEL=anthropic/claude-sonnet-4.6
```

Keep the existing `OPENROUTER_API_KEY` privately in that file. No new CNOPS key is
required for the public dataset. Existing shell variables override `.env`; use a
new terminal if an older session set a different mode. Startup loads `.env`.

```powershell
uv run --frozen --extra speech python scripts/start_service.py
```

Open http://localhost:8000, Ctrl+F5 and start a new conversation. Keep fictional jury
mode off for this agent. In a second terminal, explicitly test real CNOPS research:

```powershell
uv run --frozen python scripts/check_agent.py --cnops
```

The check requires successful CNOPS web research and cited web evidence. Historical
record fallback alone does not report a successful live search. No key or provider
body is printed. `--pharmacy` still checks business-contact research. Search incurs
OpenRouter search/token charges. No user's private key was available in the build
workspace, so live paid account compatibility/quality is not claimed.

## CNOPS reference actually imported

Source: CNOPS's “Réferentiel des médicaments” on Morocco's official Open Data portal.
The committed original workbook contains **5,917 rows**, with:

- EAN/code and trade name.
- Ingredient/DCI, strength, unit, form and pack presentation.
- Public retail price (PPV), hospital price and reimbursement base.
- Source princeps/generic flag and source reimbursement-rate field.

The original filename is `ref-des-medicaments-cnops-2014.xlsx`. The resource's
`last_modified` is **2017-12-18**. Retrieval on 2026-10-27 does not turn these prices
into current prices. Historical rows retain their edition/date and source link;
answers citing them must identify the 2014 edition. PPV is distinct from a
reimbursement base, and neither proves a patient's present entitlement or stock.

- Resource: https://data.gov.ma/data/fr/dataset/referentiel-des-medicaments/resource/094733f5-5434-4163-b837-df0e7b665127
- API: https://data.gov.ma/data/api/3/action/package_show?id=referentiel-des-medicaments
- Licence: https://opendatacommons.org/licenses/odbl/1-0/
- Original SHA-256: `e625e9f1db6193cde2db9f39853f2261d3a5c1bae03d1cbc4ac4809013f650d3`
- Original bytes and provenance: `data/raw/cnops_snapshot/`.

Public browsing initially returned 503, but the public API and actual workbook
download succeeded via the command-line client. The parser read the source bytes;
records were not generated by a model. A bounded standard-library OOXML reader
handles the first sheet without a new Excel dependency. An explicit optional
refresh command is `uv run --frozen python scripts/import_cnops.py`. Startup never
silently fetches/replaces the reference. Recheck edition/date when updating it.

## Research behavior

When web-first mode is enabled, a non-greeting normal question starts with a required
research-tool call. The first model turn offers only research tools. After evidence
returns, the same main model can use further tools and write a concise cited answer.
Named contacts and dated duty questions retain their dedicated business-research
route. Successful web answers are no longer replaced by a generic saved city list.

| Tool | Role |
| --- | --- |
| `search_cnops` | Official CNOPS/data.gov.ma web research plus the dated imported CNOPS rows |
| `search_health_web` | General health education using public-health sources |
| `search_pharmacy_web` | Published pharmacy contacts and dated duty schedules |
| `search_web` | Broader general questions, preferring primary/official sources |
| `search_pharmacies` | Local directory/GPS lookup when relevant |
| `search_medications` | Existing name-matching catalogue, explicitly separate from CNOPS |

The French source catalogue remains available for matching/research comparisons.
It cannot be used as CNOPS evidence or proof of Moroccan stock/price. CNOPS matching
uses literal names/DCIs, presentation constraints and strength equivalence, including
1 g = 1000 mg. Multiple matching pack sizes remain multiple candidates; the model
must ask which presentation when a single price would be ambiguous.

CNOPS medicine amounts require CNOPS evidence. Quoted source amounts must occur in
the cited record/excerpt; a historical record cannot be labelled a current price.
Source IDs come from tools, not model-generated URLs. General web links require
public HTTPS URLs without credentials/private IPs. The app contacts the fixed
OpenRouter endpoint rather than fetching arbitrary URLs itself.

There are at most four main-model turns, eight client-tool calls and two research
requests per turn in web-first mode, with the existing approximate 85-second overall
deadline. The search pass requests three results. Greetings can answer without
research. Web failure and absent sources stay explicit. A source citation does not
formally prove every summary, amount label or interpretation correct.

Set `ASSISTANT_WEB_FIRST=false` only to reproduce the earlier bounded demo path and
one-search budget. `ASSISTANT_WEB_SEARCH=false` disables the four web tools;
`ASSISTANT_NLU=baseline` remains the offline directory mode. The MCP stdio server
exposes the same tool registry: six tools with a key/web enabled, two local tools
otherwise. These switches are diagnostic/configuration choices, not consumer UI steps.
