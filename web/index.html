Configurer la voix sur cet ordinateur

Une seule fois : installez FFmpeg (avec ffprobe), puis téléchargez le modèle. Sous Windows / PowerShell :

winget install --id Gyan.FFmpeg --exact

Ouvrez ensuite un nouveau terminal dans le dossier du projet :

$env:PYTHONUTF8 = "1"
uv sync --frozen --extra speech
uv run --frozen --extra speech python scripts/cache_asr.py
uv run --frozen --extra speech python scripts/start_service.py

Le téléchargement initial nécessite Internet. Gardez --extra speech dans la commande de lancement.
